01

Receive real text deltas

Enable includePartialMessages. Check stream_event, content_block_delta and text_delta before accumulating text. Each callback receives a new chunk, not the full response.

02

Scope blocks correctly

Identify each block by API message ID and block index. Tool-use IDs identify execution across messages. Index zero can be reused in the next message.

03

Assemble tool input separately

Accumulate input_json_delta partial_json independently for each tool block. Parse only when its content_block_stop arrives. A stopped input block does not prove successful execution.

04

Observe actual execution

PreToolUse marks execution running. PostToolUse confirms success; native feedback records errors. Compare delayed and denied Read experiments.

05

Reconcile complete messages

Complete assistant content blocks provide authoritative text. Replace provisional block content instead of appending it again. Markdown is sanitized before rendering.

06

Forward and validate

The host sends actual observations through browser SSE. Keep raw events for inspection. Structured chunks are unvalidated; consume result.structured_output. Main-session deltas do not forward subagent tokens.
