Install the SDK, configure your key and run the classroom comparisons.

01

Prerequisites

Use Node.js 24+, API credit and a supported model. On Windows configure Git Bash when required. Python is only needed to rebuild student pages.

node --version
npm --version
02

Install and configure .env

Install dependencies, preserve an existing configuration file and enter your own model key privately.

cd .\agent-sdk\lesson36-streaming-output
npm ci
if (!(Test-Path .env)) { Copy-Item .env.example .env }
notepad .env
03

Start the application

Leave the terminal running and open the printed URL. Use all five navigation buttons.

npm start
# http://127.0.0.1:3136
04

Compare complete and partial output

Run Complete only, Text deltas and Typewriter. Watch actual chunks arrive. Complete Markdown renders with headings, lists and coloured source pages.

npm run sample:env -- complete
npm run sample:env -- text
npm run sample:env -- typewriter
05

Inspect tool input and execution

Compare one Read, two Reads, delayed Read and denied Read. Inspect indexed JSON and real execution callbacks. Delayed Read uses an explicit 3.5-second classroom hook delay.

npm run sample:env -- read
npm run sample:env -- two-reads
npm run sample:env -- slow-read
npm run sample:env -- denied
06

Validate and reconcile

Inspect structured_output from the final result. Run Reconcile and compare complete assistant text with rendered blocks. Download actual observations and run offline tests.

npm run sample:env -- structured
npm run sample:env -- reconcile
npm test

Your .env configuration

ANTHROPIC_API_KEY=your_api_key
CLAUDE_MODEL=claude-sonnet-4-6
PORT=3136
# Windows only, if needed:
# CLAUDE_CODE_GIT_BASH_PATH=C:/Program Files/Git/bin/bash.exe

Only your model key is required. Keep it local and restart after edits. Existing shell variables take precedence.

Troubleshooting

Use Node 24+, API credit and a supported model. Configure Git Bash on Windows if requested. If the port is occupied, use the printed existing-app URL or change PORT. Select an output experiment and watch actual delta arrival. Compare complete-only output with partial events. Change PORT if 3136 is occupied. The delayed Read includes a deliberate 3.5-second classroom hook delay.
